# Kairos Landing Page — Design 3

## Concept

Design 3 presents Kairos as a connected global network. A modular 3D sculpture represents businesses, talent, verification, and human-led matching coming together around one system.

Reference influence is limited to the spacious three-zone composition, integrated navigation, rounded canvas, and central 3D object. Kairos messaging, colors, functions, and identity remain original.

## Hero layout

- Pale lavender page background surrounding one large rounded canvas.
- Existing headline and eyebrow on the left.
- Original Kairos modular-network artwork in the center.
- Existing description and audience-aware actions on the right.
- Scroll cue and service highlights anchor the lower edge.
- Company and talent intent use the same layout without duplicating functionality.

## Header

- Header visually belongs to the rounded hero canvas instead of floating in a separate glass pill.
- Kairos logo stays left; current navigation stays centered/right.
- Existing audience selector, theme control, account state, CTA, and mobile menu remain functional.
- Header becomes more compact on mobile while preserving accessible controls.

## Visual system

- Outer page: pale lavender `#E8EAFF`.
- Hero canvas: lavender-white `#F0F1FF`.
- Content panels: white and soft neutral grey.
- Text: near-black `#17171A`.
- Kairos accent: magenta `#C2185B`.
- 3D materials: charcoal, ivory, lavender-grey, magenta, and pale-pink glass.
- Buttons use compact rectangular geometry matching the modular artwork.

## Sections and doodles

- Existing section copy, cards, trust content, cofounders, and actions remain.
- Decorative doodles are hidden in Design 3.
- Cards become cleaner modules with thin borders and low-shadow hover feedback.
- Section backgrounds alternate between white and light neutral surfaces for rhythm.
- No invented statistics, testimonials, or product capabilities.

## Footer

- Existing destinations, newsletter action, email, social links, and legal links remain.
- Footer uses the same neutral modular treatment and closes the rounded canvas on desktop.
- Mobile removes outer rounding for an edge-to-edge layout.

## Responsive behavior

- Desktop: three-zone hero with centered artwork.
- Tablet: two-column hero; detail content moves below headline.
- Mobile: headline, artwork, description, actions, then service highlights.
- Artwork crops by composition without hiding its main connected structure.
- Reduced-motion preference disables the scroll animation.

## Functional invariants

- Company request modal still opens from company CTAs.
- Talent signup and platform-preview links retain current destinations.
- Audience switching retains current state behavior.
- Header navigation, authentication state, theme control, consent, analytics, and footer links remain wired.
- Dark mode retains readable contrast and uses a contained treatment for the light-background 3D artwork.
